# Phase 2A GPU 验收指标（设计，未执行）

2026-10-16，UTC+8。已按新电脑RTX3060 12GB/i7-12700/16GB更新，GPU为默认路线，旧CPU-only门槛不再适用；Phase1.5历史验收记录不改。以下是后续实施的建议验收契约，不是本轮测试报告。强制项必须全部PASS且有原始证据；质量观察项报告数值/分层分布，不能冒充强制通过。若阈值需调整，应在评测前记录原因和批准版本，不得看到结果后降低标准。

## 样本与真值

使用有授权的真实中文短剧：至少10条、每条20–90秒、总计>=10分钟且>=150个可辨识话语单元，覆盖男女声、安静对白、音乐噪声、快语、哭喊、专名/数字、静音；至少2条含重叠对白/口音作为困难观察子集。另有10秒纯静音和非语音音乐负样本。Phase1.5的20秒媒体可复用副本做链路冒烟，但不能独自证明识别质量；合成正弦波不算语音样本。

两名中文标注者独立转写、标出可辨识对白起止并仲裁分歧，保留无法辨识标签和排除原因，不能默默删掉困难片段。波形+听辨定位，建议参考边界不确定度<=100ms；超过该值的样本单列。冻结素材SHA-256、原始真值、评测归一化脚本/版本、配置及测试/调参集划分；至少一半样本不用于调参。CER对比采用预先固定繁简和全半角规范、去标点空白；数字按冻结规则统一，原始CER与专名仍另报。

## GPU基准、缓存与复现步骤（后续执行）

硬件固定RTX3060 12GB；small/cuda/float16/batch4/zh/diarization=false只是起点，beam=5、VAD、上下文、对齐精度和线程一并冻结。WhisperX与faster-whisper GPU分别测试；后者应使用相应batched API才能真正评价batch参数。一次仅改变一个变量，batch4→2→1需独立记录，不能把失败批次从报告删除。

每配置冷启动1次、热身1次、正式>=5次；短片与>=2分钟素材分别报告，质量语料仍按前文>=10分钟。分别计模型加载、ASR、对齐、分段/导出、排队与端到端耗时；RTF=(完整ASR+对齐墙钟秒)/音频秒。耗尽faster-whisper生成器，GPU计时在相应后端工作完成后结束；仅torch同步不能证明CT2异步工作已结束，须完成全部结果处理。下载不计推理；离线第二次运行禁止网络并确认未重用已有字幕结果。

性能强制门槛RTF<=1，观察目标<=0.25，均为待冻结建议值而非本机成绩；20秒结果不能外推整季。GPU峰值工程估计4–8GiB，不作为验收证据；全卡限额10GiB是评测门槛，Docker普通内存限制不能硬隔离3060显存。宿主16GB、当前可用约6GiB（Docker未启动），先释放占用后实测；ASR容器初始6GiB上限、并发1、线程4，GPU前空闲目标>=8GiB，宿主可用目标>=8GiB。磁盘D盘预留>=40GiB并核实Docker虚拟盘实际位置。

缓存manifest必须覆盖ASR、中文对齐、VAD和tokenizer/运行资产；运行时本地路径+离线开关，缺资产明确失败，不能为补齐缓存自动下载。镜像digest、完整hash锁、CUDA12.8/cuDNN9实际补丁和动态库路径、torch/CT2版本需同时记录。构建阶段pip check和导入不替代真实计算。用全新隔离Compose+已验证缓存再次重建，mock与GPU两种Provider各跑一次；旧API/Worker基础依赖不增加torch。
